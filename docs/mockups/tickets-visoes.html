O que o mockup mostra

  1. Menu: Gestão de Chamados vira grupo com Visão geral (o painel atual) e Tickets.
  2. Tickets: o seletor "Visão" lista as visões habilitadas que o perfil pode ver. Cada visão já define se abre em Kanban ou Lista.
  3. Configurar visões: o botão só aparece para Admin e Super admin. No perfil "Agente" ele some (troque no topo).
  4. Abas iguais às do modelo: Principal, Condições (combinadas = E; independentes = OU), Kanban (colunas × status, arrastar, padrão) e Agrupamento.
  5. Interações que funcionam no mockup: as abas; adicionar e remover condições (o operador muda conforme o campo); adicionar, renomear e remover colunas; arrastar status entre colunas.
