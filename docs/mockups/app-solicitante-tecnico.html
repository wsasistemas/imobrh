Mockup para aprovação — App do solicitante · modo Técnico, como fica dentro do app (13/10/2026)

Feito com o CSS real do app (src/features/solicitante/solicitante.css) + só as classes novas do modo Técnico. Suas decisões:
  1. D1 · A aba Técnico só deixa entrar membros de uma equipe do CFTV (Administração › Equipes). Quem não é recebe "Seu usuário não está numa equipe do CFTV".
  2. D2 · O técnico vê todos os chamados do CFTV e, em destaque, os atribuídos a ele. Só registra atendimento nos que são dele; nos de outro técnico, lê.
  3. D4 · Sem agendamento: data e hora do cartão são a abertura e o prazo do SLA (automático).
  4. D5 · Pelo menos 1 foto para concluir como Resolvido.
  5. D6 · Tipo de resolução define o status; "O que foi feito" vai para o solicitante e vira a Solução aplicada.
